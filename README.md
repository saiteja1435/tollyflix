# 🎬 TollyFlix

TollyFlix is a Telugu Movie Discovery and Recommendation Web Application built using HTML, CSS, JavaScript, and TMDb API. Users can explore Telugu movies, search for their favorite films, view detailed movie information, watch trailers, and discover similar movies.

---

## 🚀 Features

### 🎥 Movie Discovery
- Browse Telugu Movies
- Trending Movies
- Top Rated Movies
- Upcoming Movies

### 🔍 Search & Filter
- Search Movies by Title
- Exact Search Results
- Genre-Based Filtering

### 📄 Movie Details
- Movie Poster
- Release Date
- Rating
- Runtime
- Language
- Story / Overview

### 🎬 Trailer Integration
- Watch Official Trailer directly inside the website
- Embedded YouTube Player

### 🎭 Cast & Crew
- View Cast Photos
- Character Information

### 🎞 Similar Movies
- Discover Similar Movies
- Navigate directly to movie details

### ❤️ Favorites
- Save Favorite Movies
- Local Storage Support

### 🎨 UI Features
- Dark / Light Mode
- Loading Spinner
- 3D Hover Effects
- Responsive Design
- Mobile Friendly Interface

## ⚙️ Installation

1. Clone the repository

```bash
git clone https://github.com/yourusername/tollyflix.git
```

2. Open the project folder

```bash
cd tollyflix
```

3. Open `index.html` in your browser
